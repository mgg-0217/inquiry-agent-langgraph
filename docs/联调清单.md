## 联调中发现并修复的问题（8 个）

| # | 问题 | 修复 |
|---|---|---|
| 1 | 换邮箱后基线串号（旧邮箱 UID 用到新邮箱） | 基线绑定邮箱 + UIDVALIDITY，不匹配自动重建 |
| 2 | Microsoft 畸形 `Message-ID` 导致 Python 解析崩溃 | 改用 `raw_items()` 读原始头 + 回归测试 |
| 3 | `archive` 节点不更新线程状态 | 按 comply / reject / spam 写归档终态 |
| 4 | 外发邮件不写 `messages` | dispatch 成功后写 outbound（含 `in_reply_to`） |
| 5 | `clarify` 只生成追问、未真发 | clarify 真发 + 写 outbound + 审计 |
| 6 | FOB 询盘被误判「缺目的港」 | triage prompt 按贸易术语判断（FOB/EXW 只需装运港） |
| 7 | 议价轮一律转人工 | 改为「客户目标价低于本次报价」才转人工，阶梯价内自动回 |
| 8 | IMAP provider 按 known 过滤，导致 `fetched/duplicated` 统计恒为 0 | 由入库层判重；同步成功后把基线推进到 `UIDNEXT` |
