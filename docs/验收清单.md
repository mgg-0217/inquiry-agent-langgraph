- **通过 30 项、部分 4 项、裁剪 1 项**（实体解析确认入口按用户决定不做）

  2. 议价不重复报规格（有 prompt 约束，缺断言测试）

  4. 实体解析确认入口：**用户决定不做**，接受「只认邮箱」的缺口
